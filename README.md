# Modern Admin Dashboard

لوحة تحكم حديثة لإدارة البيانات، مبنية بـ React و TypeScript.

🔗 **Live Demo:** https://modern-dashboard-eta.vercel.app


## Features
- Authentication (تسجيل دخول وصفحات محمية)
- CRUD كامل (إضافة / تعديل / حذف)
- Charts لعرض الإحصائيات
- Dark mode
- Responsive على كل الشاشات

## Tech Stack
React, TypeScript, Tailwind CSS, React Router, Axios

## Run Locally
```bash
git clone https://github.com/Ammarkassem55/Modern-Dashboard.git
cd Modern-Dashboard
npm install
npm run dev
```
